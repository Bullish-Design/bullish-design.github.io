Roxo Flex

Roxo Flex is a Hugo theme for studios, teams, and project portfolios. Each site owner sets the brand, content, section order, and visual style in the site repository.

Design decisions

The theme uses reusable page sections for the hero, selected work, and contact action. It keeps content and images in each site’s own files. Its responsive navigation and card layout follow the same structure at wide and narrow widths.

Bullish Design’s role

Roxo Flex is a Bullish Design fork of Roxo Hugo. The fork keeps the upstream history and license. Its templates and styles were rebuilt for current Hugo. The Roxo Flex repository documents its configuration and layout options.
